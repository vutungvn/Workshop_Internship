### Week 2 Objectives:

- Get familiar with the internship environment and AWS Cloud fundamentals.
- Understand AWS security basics, account setup, and IAM management (MFA, Admin Group/User/Roles).

- Explore AWS Support Plans and learn how to manage AWS support requests.
- Learn how to draw AWS architecture diagrams and attend technical sessions.
